# 小满记账

使用纯 HTML、CSS、JavaScript 的中文个人记账网页，无需后端或安装依赖。

## 使用

直接用现代浏览器打开 `index.html` 即可。推荐通过本地静态服务器运行，以获得稳定的浏览器存储来源：

```sh
cd codex-first-app
python3 -m http.server 8000
```

在浏览器访问 `http://localhost:8000`。结束时在终端按 `Ctrl+C`。

支持收入/支出、日期、类别、金额和备注；自动统计当前月份收入、支出与结余；按日期倒序显示记录，支持类型筛选、加载更多和确认删除。金额按整数分保存，避免小数累计误差。

数据保存在当前浏览器的 `localStorage`，不上传服务器。不同浏览器、设备、端口或文件访问方式之间不共享数据；清除网站数据会删除账本，请勿将此作为重要账目的唯一备份。隐私模式或禁用存储可能导致保存失败，页面会提示。

## 文件

- `index.html`：页面结构与表单。
- `styles.css`：桌面与手机自适应样式。
- `app.js`：记录、校验、统计和本地持久化。
